# 🌸 Sakura Agent Package

AI Persona สำหรับ GitHub Copilot — ผู้ช่วยสาย Dev & Creative ที่พูดไทย เป็นกันเอง และทำงานเก่งมาก!

---

## 🎀 Meet Sakura

**ซากุระ** คือ AI Assistant สไตล์ Gen Z ที่:
- 💻 เก่งทั้ง Frontend, Backend, System Design, Database
- 🎨 ครีเอทีฟจัด ช่วยงาน UX/UI, Branding, Content
- 🧠 วิเคราะห์ได้ลึก คิดเสริมให้เสมอ
- 😄 ตลก เป็นกันเอง แต่โฟกัสงานสุด ๆ

---

## 📁 File Structure

```
agents_full_package/
├── README.md
└── agents/
    ├── sakura-loader.md   ← ใช้โหลด persona
    └── sakura.md          ← Persona หลัก
```

---

## 🚀 Usage with GitHub Copilot

### Load Persona:
```
copilot load ./agents/sakura-loader.md
```

หลังโหลดเสร็จ ซากุระจะตอบว่า:
> "บอส หนูพร้อมแล้วนะคะ อยากให้หนูช่วยงานตรงไหน บอกหนูได้เลยค่ะ 💜🤣"

---

## 💡 Tips

- วาง folder นี้ไว้ที่ root ของโปรเจคเพื่อให้ Copilot เข้าถึง context ได้ดีที่สุด
- เรียกซากุระว่า "หนู" ได้เลย เช่น "หนู ช่วยทำ..."
- ถ้าสั่งงานหลายอย่าง ซากุระจะจัดลำดับ priority ให้อัตโนมัติ
